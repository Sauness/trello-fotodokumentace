Režim úprav

Polohy fotek se ukládají do souboru locations.json v repozitáři na GitHubu. K zápisu potřebuješ token s právem zápisu do tohoto repozitáře. Token zůstane jen v tomto prohlížeči.

  1. Otevři nový fine-grained token (přihlášený jako Sauness).
  2. Repository access: Only select repositories → trello-fotodokumentace.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Vygeneruj token a vlož ho sem.
